ZARMAL LIFE — REAL ANDROID PROJECT

App name: Zarmal Life
Package: com.zarmallife.app
Version: 1.0.0

دا د Android Studio اصلي پروژه ده، نه یوازې HTML فایل.
پکې د Zarmal Life B2B UI په Android APK کې د WebView له لارې bundled شوی.
Offline معلومات د موبایل LocalStorage کې ساتل کېږي.

د APK جوړولو لپاره:
1. پروژه Android Studio ته Import کړئ.
2. Gradle Sync بشپړ کړئ.
3. Build > Generate App Bundle(s) / APK(s) > Generate APK.
4. app-release.apk به د app/build/outputs/apk/release/ کې جوړ شي.

د راتلونکي Online نسخه لپاره باید Backend/Supabase، Login، Admin، Customer accounts، Orders sync او server security اضافه شي.
